Projeto de criação de uma loja de tecnologia integrada à **API do Mercado Livre**, desenvolvido como projeto prático no curso da **DevStars**. A aplicação foi construída com foco em **performance**, **segurança de dados** e, primordialmente, **Acessibilidade Web Universal**.

## 🚀 Funcionalidades Atualizadas
- **Busca Inteligente:** Integração assíncrona com a API do Mercado Livre para listagem dinâmica de produtos.
- **Ecossistema de Carrinho:** Lógica avançada para gestão de quantidades, soma de subtotais e remoção de itens.
- **Cálculo de Entrega:** Integração com a API **ViaCEP** para validação de endereços e frete.
- **Experiência Gamificada:** Feedback visual com efeito de confetes (`canvas-confetti`) e alertas de sucesso na finalização da compra.
- **Otimização SEO:** Implementação de Meta Tags para alto índice de indexação no Google e compartilhamento em redes sociais.

## 🛠️ Tecnologias e Padrões
- **Arquitetura Front-end:** HTML5 Semântico para garantir estrutura lógica e SEO.
- **Estilização Avançada:** CSS3 com animações de entrada (`keyframes`), foco visível para teclados e design **Mobile-First**.
- **Framework:** **Bootstrap 5.3** para um sistema de grid robusto e responsivo.
- **JavaScript Moderno (ES6+):** 
  - `Async/Await`: Gerenciamento eficiente de promessas nas APIs.
  - `Data Sanitization`: Tratamento de strings para prevenir ataques de injeção (XSS).
  - `DOM Management`: Centralização de seletores para facilitar a manutenção futura.

## ♿ Acessibilidade e Responsividade Plena
O projeto obedece rigorosamente aos padrões de uso para **PCDs (Pessoas com Deficiência)** e não PCDs:
- **Navegação:** Suporte total para navegação via teclado e compatibilidade com leitores de tela (NVDA/Jaws) através de atributos `ARIA`.
- **Visual:** Contraste de cores otimizado e `alt text` em todas as imagens.
- **Sistemas:** Testado em Windows, macOS, Linux, iOS e Android, garantindo funcionamento em diversos navegadores (Chrome, Safari, Edge, Firefox).
